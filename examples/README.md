# Examples

The scripts are small examples showcasing the main features:

- `moons_density_comparison.py`: synthetic two-moons density estimation with
  axis-aligned and random-rotation forests.
- `rotation_forest_anomaly.py`: normal-only anomaly scoring with a
  random-rotation forest.
- `bayes_classifier.py`: class-conditional density-ratio classification.
- `basic_tree.py`: a minimal single-tree density example.
